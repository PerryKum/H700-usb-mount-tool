# H700系列 挂载usb小工具

该工具用于 **H700 官方固件** ，把tf卡roms分区挂载成usb存储设备（典型场景：拷贝 ROMs、备份存档等）。

---

## 使用前请确认

| 项目 | 说明 |
|------|------|
| 固件 | 安伯尼克 **H700 官方系统**（脚本按该机 `/sys/class/udc`、configfs 等环境编写） |
| 连线 | 启动软件后，用 **能传输数据的数据线** 连接掌机的 DC 口（非OTG口）与电脑|
| 存储 | 优先挂载卡2 若无卡2则默认回滚到卡1（卡1未详细测试） |

---

## 使用方法（推荐顺序）

### 1. 放进 ROMS/APPS，机器启动后在 应用 → APPs 中启动即可

### 2. 按 B 或 select + start 结束挂载（建议现在电脑上安全退出后再退出挂载，避免破坏文件系统）

**注意：** 读写过程中不要拔掉 USB；退出流程完成后再拔线更安全。

# 以下内容为开发相关，不感兴趣可以略过

启动后脚本会：

1. 把自身复制到内存临时路径再执行（避免 TF 被卸载后脚本「消失」导致异常）
2. 自动选择要导出给电脑的存储设备并挂载 ROMS 分区作为 **USB 大容量存储设备**，优先卡2，若无则回滚到卡1
3. 若存在提示图，则全屏显示操作说明
4. 进入按键监听，等待你按组合键退出

## 常见问题

**启动后等一会儿就退出，没有进 U 盘模式**  
- 是否 **root** 运行  
- 是否存在可用 **USB 控制器**（`/sys/class/udc`）  
- 是否能找到可导出的 **块设备**（TF 是否在位、是否被占用）

**电脑不识别盘符**  
- 换数据线、换 USB 口；Windows 可尝试设备管理器里是否出现大容量设备  
- 部分电脑前置口供电不足，换主板直连口试

**有提示图但不显示 / 黑屏**  
- 检查官方系统是否自带或可调用 **mpv**（脚本会依次尝试包内 `res/mpv`、`/usr/bin/mpv`、`PATH` 中的 mpv）

**RG28xx 外接 HDMI 相关**  
- 脚本内对 **RG28xx + 未接 HDMI** 时会为提示图增加旋转参数；其它机型按默认方向显示。
